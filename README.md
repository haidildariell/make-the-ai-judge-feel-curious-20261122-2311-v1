Entry for the [make.fun competition "Make the AI judge feel curious"](https://make.fun/c/make-the-ai-judge-feel-curious-20261122-2311).

`main.py` (Python 3.13) writes one short text to `/output/entry.txt`: a single
concrete mystery, plainly told, that ends before it is explained. No network,
fully deterministic.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
